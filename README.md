# Снежинки Лобачевского

Интерактивная мастерская гиперболических орнаментов в диске Пуанкаре. Шесть конструкций, четыре градиентных цвета свечения, редактируемые числа в формулах, экспорт PNG и SVG.

Публичная сборка зашифрована AES-256-GCM с PBKDF2-SHA256 (600 000 итераций). Пароль и расшифрованные исходники в репозитории не хранятся. Это статическое шифрование, а не серверная авторизация.

Включены две предыдущие версии для сравнения, также зашифрованные.
